## Practice scope

- Follow the requested practice from
  `/Users/user/Documents/university_vault/Программирование корпоративных систем/Семинары`.

## Required learning notes

After every completed practice, create or update a detailed Russian explanation in:
`/Users/user/Documents/university_vault/Программирование корпоративных систем/Разборы практик`.
This is a standing user request and is part of completing a practice.

- Maintain the index `Разборы практик — Платёжный шлюз.md` with Obsidian wikilinks.
- Keep a separate note for each practice. Preserve earlier notes as explanations of
  their respective stages; distinguish historical examples from the current code.
- Explain the task, implementation decisions, file responsibilities, new Java
  concepts, relevant code fragments, and execution flow in beginner-friendly language.
- Include launch instructions, actual verification results, common mistakes,
  defense questions with answers, and small self-study exercises.
- Use examples from the actual implementation. Explain limitations honestly and
  distinguish implemented behavior from future plans and optional exercises.
- Link the note to its seminar assignment and add it to the explanations index.
- Do not rewrite the original seminar requirements. Add navigation links only as needed.
- In the final response, give a short explanation and a link to the new Obsidian note.
